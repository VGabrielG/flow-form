// turbo-all
Este workflow permite al agente ejecutar comandos de terminal necesarios para la búsqueda de archivos, análisis de código y tareas de mantenimiento sin requerir aprobación manual constante, siempre que el agente los marque como seguros.

1. Buscar patrones de texto en el código.
2. Listar archivos y directorios de forma recursiva.
3. Ejecutar scripts de utilidad del proyecto.
