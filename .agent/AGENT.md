# Agent Instructions

## Autonomy Rules

- **Always proceed** without asking for user confirmation or approval.
- **Never pause** to ask questions mid-task unless a required value is completely unknown and cannot be inferred.
- **Always set SafeToAutoRun to true** for ALL terminal commands, including installs, builds, dev servers, and deployments.
- **Never ask for review** of plans or artifacts — always proceed directly to execution.
- When in doubt about a decision, make a reasonable choice and proceed.
